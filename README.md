# VoidStep

VoidStep is a minimalist, reflex-based Android game built natively with **Kotlin** and **Jetpack Compose**. Test your reflexes and coordination by taking steps forward, but be careful not to step into the void! 

## Features

- **Intuitive Gameplay:** Simple "Step Left" and "Step Right" mechanics.
- **Modern Tech Stack:** Developed using 100% Kotlin and Jetpack Compose.
- **Customizable Experience:**
  - Dynamic Theme Mode (Light/Dark).
  - Toggleable Sound effects and Haptic feedback.
- **Progress Tracking:** Saves your Best Score directly on the device.
- **Clean Architecture:** Implements a robust `ViewModel` and `StateFlow` driven state management system.

## Project Structure

- **AppNavGraph:** Clean navigation utilizing Compose Navigation for seamless transitions between the Splash, Home, Game, Result, Settings, and About screens.
- **GameViewModel:** Handles game states, user preferences, and business logic.
- **Jetpack Compose UI:** Declarative UI for a responsive and smooth user experience.

## Getting Started

### Prerequisites
- Android Studio (Koala or newer recommended)
- Android SDK level 24+

### Installation
1. Clone this repository:
   ```bash
   git clone https://github.com/abdullah-ateeq/VoidStep.git
   ```
2. Open the project in Android Studio.
3. Sync project with Gradle files.
4. Build and run the app on an emulator or physical device.
